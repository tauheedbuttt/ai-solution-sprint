# Individual Assignment

1. Create your own custom instructions in ChatGPT or Gemini, first version is enough, refine later
2. Try generating presentation draft or something you normally do with AI, using five-step prompt while your custom instructions are enabled (try to find the difference)
3. Try reading PDF with Copilot or reading Excel file with any AI tool you like
4. Check your memory settings in ChatGPT

If you are familiar with most of these or fast, use remaining time for checking similar settings in other AI tools you use often.

Time: approx 20 mins

Feel free to ask for help!

Example structure for good prompt:
1. Role prompting
2. Context
3. What
4. How
5. Detail
