# ChatGPT, Claude, Copilot, Gemini

- Tools include: ChatGPT, Copilot, Gemini, Claude, runwayml.com (for videos), Perplexity, Grammarly (writing in foreign languages) etc.
- Tools can read PDFs and other attachments, upload a PDF, Excel, or e.g. image and ask for summary or any insights about it
- E.g. Copilot can read web pages, ChatGPT and Gemini works with that (still, sometimes not)
- In ChatGPT and Gemini, can use saved custom instructions and memory, examples shown on next slides
- Prompting is key, better your prompts, better results
- Example structure for good prompt: 1. Role prompting, 2. Context, 3. What, 4. How, 5. Detail
- AI assistants available even in tools like PowerPoint and Excel, try Gemini/Google slides etc.
