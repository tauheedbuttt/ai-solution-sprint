# Conventions

Product and UI decisions that apply across app, not tied to one screen. Add new ones as they come up.

## UI: minimal, actionable over text-heavy

Build UI as minimal as possible. Favor actions over explanation.

- Default to buttons, toggles, cards over paragraphs.
- If a screen needs a paragraph to explain itself, redesign it instead.
- Show only what user needs to decide right now. Push detail behind a tap, not onto main view.
- One primary action per screen. Secondary actions stay visually secondary.
- Copy: short labels, no filler words ("please", "simply", "just click").
